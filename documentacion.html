Anticipo (advance) Número decimal Moneda MXN 1000 Monto de anticipo registrado al momento de cotizar.
Saldo pendiente (balance) Número decimal Moneda MXN 1220 Saldo restante calculado como el total menos el anticipo.

C = Crear / Insertar registros L = Leer / Consultar en tiempo real A = Actualizar / Modificar registros E = Eliminar registros (solo vía Consola de Administración)
Módulo / Pantalla Rol Permitido Clientes Cotizaciones Pedidos Configuración Reglas de Negocio y Disparadores
Panel Principal (Dashboard) Administrador — L L — Calcula ingresos cobrados (pagos de pedidos excluyendo Cancelado), conteo de entregas pendientes y total de cotizaciones.
Cotizador Vendedor C / L / A C / L / A C L Lee tarifas vigentes; crea la cotización; registra o actualiza al cliente; convierte borradores aprobados en pedidos oficiales.

Base de Clientes Administrador y Vendedor L — — — Muestra el directorio sincronizado de clientes frecuentes, historial de entregas y saldo de puntos de lealtad.
